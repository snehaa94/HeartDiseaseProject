# 🧹 Data Preprocessing

The categorical variables needed to be converted into numerical values before training Machine Learning models.

## One-Hot Encoding

The project uses:

```python
df_encoded = pd.get_dummies(df, drop_first=True)
```

`drop_first=True` helps remove one category from each categorical feature to avoid redundant dummy variables.

The encoded dataset contains features such as:

```text
Sex_M
ChestPainType_ATA
ChestPainType_NAP
ChestPainType_TA
RestingECG_Normal
RestingECG_ST
ExerciseAngina_Y
ST_Slope_Flat
ST_Slope_Up
```

The encoded values were then converted into integers:

```python
df_encoded = df_encoded.astype(int)
```

---

# ✂️ Train-Test Split

The dataset was divided into training and testing sets.

```python
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    stratify=y,
    test_size=0.2,
    random_state=42
)
```

### Split Details

```text
80% → Training data
20% → Testing data
```

`random_state=42` is used to make the split reproducible.

`stratify=y` helps maintain the class distribution of the target variable between the training and testing datasets.

---

# 📏 Feature Scaling

Since several Machine Learning algorithms are sensitive to feature scale, `StandardScaler` was used.

```python
scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

### Important

The scaler is:

```text
fit → only on training data
transform → training and testing data
```

This prevents information from the test set from being used while fitting the scaler.

# 📈 Model Evaluation

The models were evaluated using:

* Accuracy
* F1 Score

The evaluation code was:

```python
for name, model in models.items():
    model.fit(X_train_scaled, y_train)

    y_pred = model.predict(X_test_scaled)

    acc = accuracy_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)

    results.append({
        'Model': name,
        'Accuracy': round(acc, 4),
        'F1 Score': round(f1, 4)
    })
```

# 💾 Model Saving

The selected KNN model and preprocessing objects were saved using `joblib`.

```python
import joblib

joblib.dump(models['KNN'], 'KNN_heart.pkl')
joblib.dump(scaler, 'scaler.pkl')
joblib.dump(X.columns.tolist(), 'columns.pkl')
```

### Saved Files

| File            | Purpose                       |
| --------------- | ----------------------------- |
| `KNN_heart.pkl` | Trained KNN model             |
| `scaler.pkl`    | Fitted StandardScaler         |
| `columns.pkl`   | Training feature-column order |

Keeping the scaler and feature-column order is important because new Streamlit inputs must be processed in the same way as the training data.

# 🌐 Streamlit Application

A Streamlit web application was created to make the trained model interactive.

The application allows the user to enter features such as:

* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise-Induced Angina

After clicking **Predict**, the application processes the input and sends it to the trained KNN model.
